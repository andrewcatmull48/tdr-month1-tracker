# TDR Month 1 Tracker

Offline-capable PWA for logging TDR products over 28 days.

## GitHub Pages
1. Open Settings → Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Select main and /(root), then Save.
4. Wait for GitHub Pages to publish.

## iPhone Home Screen
Open the published site in Safari, tap Share → Add to Home Screen.

Entries are saved in local browser storage on this device; they do not sync between devices.

This is a stock/logging tool, not a clinical meal plan. Follow your coach's instructions for portions, combinations, bars, hydration and diabetes/medication monitoring.
