# TDR Month 1 Tracker

Offline-capable PWA for logging TDR products over 28 days.

## GitHub Pages
1. Open Settings → Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Select main and /(root), then Save.
4. Wait for GitHub Pages to publish.

## iPhone Home Screen
Open the published site in Safari, tap Share → Add to Home Screen.

Entries are saved in local browser storage on this device; they do not sync between devices.

This is a stock/logging tool, not a clinical meal plan. Follow your coach's instructions for portions, combinations, bars, hydration and diabetes/medication monitoring.

## Timed daily portion tracker

The Today screen includes the weekday schedule: 09:00, 11:00, 13:00, 15:30, 18:45 and 20:45. The 15:30 bar is one item that counts as two programme portions, giving the fixed daily target of seven portions. Each planned item has an editable scheduled time; ticking “Had it” records the actual time and advances the “Next” prompt. Schedule and taken-time data are saved locally in this browser on this device. Follow your coach's prescribed portion count and guidance.
