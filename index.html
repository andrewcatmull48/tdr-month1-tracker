One-time Apple Shortcut setup
  1. Open Shortcuts and create a shortcut named exactly Create TDR Reminders.
  2. Add Get Text from Input, then Split Text using New Lines.
  3. Add Repeat with Each item from the split text.
  4. Inside the repeat, split the repeat item by |.
  5. Use item 1 as the due date/time and item 2 as the reminder title. Add a New Reminder action and choose your preferred Reminders list.
  6. End Repeat and save. Allow Shortcuts access to Reminders when asked.

The main page reminder button sends the selected day’s entries to this shortcut.

Progress is saved in this browser on this device. It does not sync between devices.
